# 779. K-th Symbol in Grammar

## Step 1

「新しい行を作るとき、前の行を見て0を01に、1を10に置き換えたものを入れる」という規則を持つテーブルを考える。n行目のk番目の数字を返す。

- 何かしらの文法規則との関係があるんだろうか？前に別の問題で常識として言われていたものがあった。
- 各行の要素数は $2^{n-1}$ 個になる。三角形、再帰構造を持ち、どの部分を切り取っても同じ形になっていそう。
  - 一つずつ作っていくとTLEになるだろう。
- 思いつかないのでヒントを見てみる。偶奇を使うのかなあと思う。kが偶数であれば前の行の数列の対応する数字から出てくるものの2番目、奇数であれば1番目。とはいえ今一つピンとこないので答えを見る。
  > Try to represent the current (N, K) in terms of some (N-1, prevK). What is prevK ?

対称性があるのか。前後半の長さは同じ、前半は前の行をトレースしたもので後半はフリップしたもの。したがって、後半のある値は前半の対応する位置の値をひっくり返したものになっている。前後半どちらにあるかは計算できる。`step1.cpp` に書いた。

- 時間計算量 $O(N)$、空間計算量 $O(N)$。

## Step 2

偶奇でやる方法。自分が最初考えたのでやっていくとこうなるのかな。思いつきやすそうな気がする。kの位置を遡っていくイメージは湧かなかった。

```cpp
class Solution {
public:
    int kthGrammar(int n, int k) {
        if (n == 1 && k == 1) {
            return 0;
        }

        bool isOdd = (k % 2) == 1;

        int k_prev = k + 1 >> 1;
        int prev = kthGrammar(n - 1, k_prev);

        if (prev == 0 && isOdd || prev == 1 && !isOdd) {
            return 0;
        } else {
            return 1;
        }
    }
};
```
