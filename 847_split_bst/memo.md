# 776. Split BST

## Step 1

二分探索木を分割し、ノード数がより多い方を返す。ノード数が同じであれば根の値がより大きい方を返す。分割は値が基準値よりも大きいかどうかで決める。また、元の木構造のうち親子関係は分割後にも保たれていなければいけない。

- 制約：`n <= 50`

走査しながら分割後の木にノードを割り振っていきたい。ノード数も同時にカウント？15分くらい考えて書けなかったので答えを見る。

新しく木を作るのではなく、ポインタを付け替えていく問題だと捉える。例えば `root->val <= target` であれば `root` は左側の木に入れて、右部分木だけさらに分割することになる。

- `step1.cpp` に書いた。
- 時間計算量 $O(N)$、、空間計算量 $O(h)$（$h$ は木の高さ）。
